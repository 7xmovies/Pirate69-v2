# Pirate69 🏴‍☠️

![Pirate69](https://img.shields.io/badge/Status-Active-success) ![License](https://img.shields.io/badge/License-MIT-blue)

Pirate69 is a modern, responsive web application built with React and Express that aggregates and serves media content from multiple sources, providing users with a seamless browsing and viewing experience.

## ✨ Features

*   **Multi-Source Aggregation**: Pulls content dynamically from various sources including Hollywood, Bollywood, and Adult content.
*   **Modern UI/UX**: Built with Tailwind CSS for a sleek, responsive, and mobile-friendly experience.
*   **Dark/Light Mode**: First-class support for both themes to suit your viewing preference.
*   **Watchlist & History**: Keep track of what you want to watch and what you've recently viewed.
*   **Advanced Search & Filtering**: Easily find your favorite movies and shows by category or title.
*   **Robust Backend**: Custom Express server for efficient HTML parsing and API routing.

## 🚀 Tech Stack

*   **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons
*   **Backend**: Node.js, Express, Cheerio (for web scraping)

## 🛠️ Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/7xmovies/Pirate69.git
    cd Pirate69
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```
    This will start the full-stack environment (Vite frontend + Express backend) on `http://localhost:3000`.

4.  **Build for production:**
    ```bash
    npm run build
    npm start
    ```
